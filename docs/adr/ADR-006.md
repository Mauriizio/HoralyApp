# ADR-006 Generación local de PDF de horario con jsPDF

## Estado

Aceptada.

## Contexto

El horario académico debe exportarse como PDF profesional sin capturar el DOM, sin servicios remotos y sin enviar datos del estudiante fuera del navegador. El renderer artesanal previo solo concatenaba bytes con prefijo `%PDF-`, insuficiente para una tabla semanal real.

## Decisión

Usar `jspdf` fijado en `package.json` detrás de `SchedulePdfRenderer`. La dependencia se ejecuta en cliente, usa licencia permisiva compatible con el proyecto y permite generar A4 horizontal, texto, líneas, colores, páginas y metadatos sin backend externo.

## Consecuencias

El dominio conserva `ScheduleDocumentModel` y `SchedulePdfOptions`, por lo que se puede cambiar el adaptador en el futuro. El correo no se modela por defecto y no se transmite a servicios remotos.
