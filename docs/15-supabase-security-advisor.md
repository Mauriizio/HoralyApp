# Compatibilidad: Supabase Security Advisor

La guía autoritativa está en
[`technical/15-supabase-security-advisor.md`](technical/15-supabase-security-advisor.md).

La protección contra contraseñas filtradas requiere plan Supabase Pro. HoralyApp
permanece en plan Free, por lo que el riesgo queda aceptado. Al cambiar de plan,
el propietario debe activar inmediatamente la protección desde el Dashboard.
